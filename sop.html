STANDARD OPERATING PROCEDURE (SOP)

Manajemen Data Kegiatan Skrining RHD - YJI 2026

A. TAHAP PERSIAPAN SEBELUM KEGIATAN (PRA-SKRINING)
1. Tata Letak Posisi Alur Lapangan ▼
  • Meja Registrasi (1) & Antropometri (2): Tempat pertama anak datang. Petugas mengentri NIK, data demografi, serta pengukuran BB/TB. Struk barcode identitas dicetak di meja ini.
  • Ruang Tunggu Dokter: Anak memegang struk barcode masing-masing sambil mengantre panggilan pemeriksaan.
  • Meja Pemeriksaan Echo / Dokter: Dokter menggunakan mesin Lumify. Dokter memindai barcode anak untuk mengisi Patient ID di Lumify, melakukan pemeriksaan, lalu men-scan ulang di aplikasi screening untuk menentukan status REDFLAG / NORMAL.

[Opsi 1: Meja Registrasi dan Antropometri dipisah. Dianjurkan untuk kegiatan skrining yang melibatkan banyak peserta]


[Opsi 2: Meja Registrasi dan Antropometri digabung. Dianjurkan untuk kegiatan skrining yang melibatkan sedikit peserta]

2. Antisipasi Kendala Sinyal & Aktivasi PWA ▼

Aplikasi ini didukung oleh sistem Progressive Web App (PWA) yang memungkinkannya beroperasi penuh tanpa jaringan internet. Namun wajib mengikuti aturan ini:

  1. H-1 Kegiatan: Seluruh PIC perangkat (laptop/tablet petugas & HP dokter) WAJIB membuka website minimal 1x saat kondisi online internet.
  2. Langkah ini bertujuan agar mesin browser (Service Worker) mengunduh seluruh skrip, font, gambar, dan pustaka scanner/barcode ke memori lokal perangkat.
  3. Setelah berhasil dibuka sekali saat online, disarankan untuk melakukan klik "Add to Home Screen" (Tambahkan ke Layar Utama) agar aplikasi terpasang seperti aplikasi native dan siap dipakai offline total di sekolah tujuan.
3. Alur Disiplin Pengisian Data Lapangan ▼
  • Standardisasi Kode Lokasi (Mutlak): Kode lokasi skrining (2 digit, 01-99) harus sudah disepakati di tingkat PIC Wilayah sebelum hari H dan tidak boleh berubah di tengah jalan karena kode ini menyusun keunikan ID peserta.
  • Disiplin Nomor Meja: Jika dalam 1 lokasi terdapat lebih dari 1 meja registrasi, pastikan nomor meja diinput berbeda (Meja 1, Meja 2, dst) untuk menghindari bentrok generate nomor urutan otomatis antar-tab/perangkat.
  • Navigasi Cepat: Petugas diimbau membiasakan diri menggunakan tombol Tab pada keyboard fisik untuk berpindah antarkolom input form demi efisiensi waktu entri.
4. Barcode & Instalasi Printer Thermal Portable ▼
  1. Pastikan software Recta Host sudah terpasang dan berjalan aktif di laptop/perangkat perantara printer.
  2. Nyalakan Bluetooth/sambungkan kabel USB printer thermal portable ukuran kertas 58mm.
  3. Di aplikasi entri, klik tombol 🔌 Setting Printer di kanan atas, isi token APPKEY dan nomor HOST/PORT sesuai setelan Recta Host Anda.
  4. Klik "Hubungkan Printer". Jika sukses, status akan berubah menjadi hijau (Printer Terhubung).
  5. Setiap data registrasi selesai disimpan, printer akan otomatis mencetak struk barcode yang berisi ID Unik Peserta, NIK, Nama, Jenis Kelamin, dan Tanggal Lahir.
5. Pencatatan Redflag & Keterangan Dokter ▼
  • Dokter pemeriksa echo membuka fitur "Screening & Redflag" pada HP/Tablet pribadi.
  • Arahkan kamera ke struk barcode pasien anak. Setelah ID terdeteksi, kamera otomatis mati dan memunculkan pop-up opsi screening.
  • Jika ditemukan tanda bahaya klinis (misal: keterlibatan katup patologis pada echo), centang kotak YA, REDFLAG.
  • Isi kolom keterangan klinis tambahan (misal: derajat regurgitasi katup atau gejala bising jantung). Kolom ini opsional namun sangat disarankan diisi jika berstatus redflag. Klik simpan untuk menyalakan kembali kamera pasien berikutnya.
B. TAHAP SETELAH SELESAI KEGIATAN (PASCA-SKRINING)
1. Otorisasi & Kode Akses Upload Data ▼

Untuk mencegah kebocoran data medis dan kiriman spam dari pihak luar, proses pengunggahan data rekap lokal ke server Cloud dikunci dengan sistem otorisasi:

  • Gunakan kode akses otorisasi resmi tim yang sudah ditentukan.
  • Kode akses ini wajib dimasukkan ke dalam form input tepat sebelum menekan tombol unggah cloud ataupun saat akan mengakhiri sesi pembersihan memori lokal perangkat.
2. Dokumentasi Lumify & Ekstraksi Link Folder Drive ▼
  1. Setelah seluruh pemeriksaan rampung, pindahkan file rekaman gambar/video echo dari mesin Lumify ke Google Drive. Satukan seluruh folder anak ke dalam satu folder induk utama kegiatan.
  2. Copy link tautan folder induk utama tersebut dari Google Drive.
  3. Buka menu 📂 Ekstraksi Link Folder pada halaman utama aplikasi.
  4. Paste link folder Drive tersebut ke kolom yang disediakan, lalu klik "Ekstrak Daftar Folder".
  5. Sistem Apps Script akan mengekstrak seluruh nama subfolder (nama pasien/ID) beserta link URL-nya secara massal dalam hitungan detik.
  6. Klik tombol 📋 Copy Hasil Ekstraksi, lalu paste (Ctrl+V) langsung di Google Sheets Master Data untuk memetakan dokumentasi digital secara otomatis.
3. Verifikasi Akhir & Rekonsiliasi Data Cloud ▼
  1. Klik tombol ❌ Akhiri Sesi di bagian atas menu data entri, ketik kode akses valid, lalu pilih opsi ☁️ Upload Data ke Cloud.
  2. Tunggu hingga muncul notifikasi sukses dari server Apps Script yang mengonfirmasi jumlah data yang berhasil masuk.
  3. PENTING: Jangan terburu-buru melakukan hapus data lokal! PIC wajib membuka Google Sheets utama terlebih dahulu untuk memverifikasi secara visual bahwa baris data yang diunggah sudah sinkron dan lengkap sesuai jumlah riil anak yang diperiksa hari itu.
  4. Jika data di Google Sheets dipastikan sudah aman dan utuh, kembali ke aplikasi, masukkan kembali kode akses di modal, lalu klik 🔴 Akhiri Sesi (Hapus Data Lokal) untuk membersihkan memori perangkat dan bersiap untuk sesi sekolah/hari berikutnya.
